# 🌊 Thien-le-travel - Web Đăng Ký Tour Du Lịch Vũng Tàu

Ứng dụng web hỗ trợ tìm kiếm, tra cứu thông tin và đăng ký các tour du lịch trải nghiệm tại Vũng Tàu.

## 🚀 Tính năng chính
- 📍 **Khám phá Tour:** Danh sách các tour du lịch nổi bật (Biển Bãi Sau, Tượng Chúa Kito, Ngọn Hải Đăng, Trải nghiệm ẩm thực...).
- 📝 **Đăng ký Tour trực tuyến:** Form đăng ký thông tin khách hàng, số lượng vé, chọn ngày khởi hành.
- 💰 **Tính toán chi phí tự động:** Tự động tính tổng tiền theo số lượng người và dịch vụ đi kèm.
- 📊 **Quản lý đăng ký:** Trang xem lại danh sách đơn đăng ký tour (cho Admin/Giảng viên duyệt).

## 🛠️ Công nghệ sử dụng
- **Python 3.x**
- **Streamlit** (Giao diện ứng dụng Web)
- **Pandas** (Xử lý và lưu trữ dữ liệu)

## 📦 Hướng dẫn cài đặt & Chạy ứng dụng

```bash
# 1. Clone repository
git clone [https://github.com/levuduythien2005-ui/Thien-le-travel.git](https://github.com/levuduythien2005-ui/Thien-le-travel.git)

# 2. Cài đặt thư viện
pip install -r requirements.txt
